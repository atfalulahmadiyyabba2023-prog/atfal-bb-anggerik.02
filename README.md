# Majlis Atfal-ul-Ahmadiyya B.B. Anggerik

GitHub/Vercel-ready starter connected to Supabase.

## Setup
1. Copy `.env.example` to `.env.local`.
2. Add your Supabase Project URL and Publishable Key.
3. Run `npm install` then `npm run dev`.
4. Run `supabase/schema.sql` in Supabase SQL Editor.
5. Deploy the repository to Vercel and add the same environment variables.

Never put a Supabase service-role key in this frontend repository.
